# Python-Pandas-EDA-Netflix

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python, Pandas, Matplotlib, and Seaborn.

## Dataset

The dataset contains 8,807 Netflix titles and 12 columns, including content type, title, director, cast, country, release year, rating, duration, genres, and description.

### Dataset Source

Kaggle: https://www.kaggle.com/datasets/shivamb/netflix-shows

## Analysis Performed

- Dataset shape and structure
- Column data types and memory usage
- First and last rows
- Missing value analysis
- Summary statistics
- Categorical value counts
- Movies vs TV Shows analysis
- Release year distribution
- Content rating analysis
- Country-wise content analysis
- Data visualizations

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings

- Movies are more numerous than TV Shows in the dataset.
- Most Netflix content was released in recent years.
- The director column has the highest number of missing values.
- TV-MA and TV-14 are among the most common content ratings.
- The United States and India are major content-producing countries in the dataset.
